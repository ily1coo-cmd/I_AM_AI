# 🤖 Telegram-бот в твоём стиле

Бот читает экспорт твоего Telegram-чата и общается точно как ты.

---

## 📦 Установка

```bash
pip install -r requirements.txt
```

---

## ⚙️ Настройка (3 шага)

### 1. Получи токен бота
- Открой [@BotFather](https://t.me/BotFather) в Telegram
- Напиши `/newbot`, дай имя и username
- Скопируй токен вида `123456789:AAF...`

### 2. Создай управляющего бота и получи Gemini API ключ
- В [@BotFather](https://t.me/BotFather) создай второго бота для управления.
- Получи ключ Gemini в [Google AI Studio](https://aistudio.google.com/).
- Узнай свой Telegram ID через любого бота, который показывает user ID.

### 3. Подготовь экспорт чата
- В Telegram Desktop: **Настройки → Экспорт данных → Экспорт выбранных чатов**
- Выбери любой чат с большим количеством ТВОИХ сообщений (личка с другом, группа)
- Формат: **JSON**
- Скопируй `result.json` рядом с `bot.py`

### 4. Задай переменные окружения

```dotenv
BOT_TOKEN=123456789:AAF...             # основной бот
ADMIN_BOT_TOKEN=123456789:AAF...       # управляющий бот
GEMINI_API_KEY=...                     # ключ Google Gemini
ADMIN_USER_ID=123456789                # твой Telegram ID
```

В PowerShell:

```powershell
$env:BOT_TOKEN = "..."
$env:ADMIN_BOT_TOKEN = "..."
$env:GEMINI_API_KEY = "..."
$env:ADMIN_USER_ID = "123456789"
```

## 🚀 Запуск

```bash
python bot.py
```

## 💬 Команды бота

| Команда | Действие |
|---------|----------|
| `/start` | Приветствие |
| `/reset` | Очистить историю диалога |

В управляющем боте:

| Команда | Действие |
|---------|----------|
| `/stop` | Остановить автоответы и получать новые сообщения уведомлениями |
| `/resume` | Возобновить автоответы |
| `/status` | Показать состояние бота |
| `/users` | Показать ID пользователей |
| `/reply USER_ID текст` | Отправить ручной ответ через основного бота |

## 🔧 Дополнительные настройки

В `bot.py` можно изменить:

```python
MAX_STYLE_MESSAGES = 300   # Сколько твоих сообщений брать для анализа
MAX_HISTORY = 20           # Сколько сообщений помнит бот в одном диалоге
```

Чем больше `MAX_STYLE_MESSAGES` — тем точнее стиль, но чуть дольше старт.

## ❓ Частые вопросы

**Бот не запускается — ошибка с result.json**  
→ Убедись, что файл лежит рядом с bot.py. Можно указать полный путь в `RESULT_JSON_PATH`.

**Как сделать бота активным 24/7?**  
→ Залей на VPS (например, [Hetzner](https://www.hetzner.com), [DigitalOcean](https://www.digitalocean.com)) и запусти через `screen` или `systemd`.

**Бот отвечает не в моём стиле**  
→ Попробуй экспортировать чат с бо́льшим количеством твоих сообщений, или увеличь `MAX_STYLE_MESSAGES`.
